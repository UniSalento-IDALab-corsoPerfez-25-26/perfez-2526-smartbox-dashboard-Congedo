Nota

Le statistiche contano solo le salite di livello (un allarme = un episodio). I dati restano nel backend per il periodo di conservazione configurato e poi vengono cancellati automaticamente. Il sistema non deve essere usato per valutare la prestazione del lavoratore (limitazione della finalità, tesi §3.16).

Validazione offline (capitolo 5)

Carica eventi.csv prodotto dalla smartbox o dal notebook e le annotazioni (inizio_s,fine_s,tipo). Opzionale: indicatori.csv (t,face,ear,mar,pitch, esportato dalla demo live) per la tabella di sensibilità della soglia EAR. Tutto viene calcolato nel browser: i file non vengono inviati a nessun server.
